# KYC / AML Investigation Copilot

An AI-powered investigation assistant for banking compliance teams.

## Business Problem

Banks must verify customer information, review documents, and investigate suspicious activities to comply with Know Your Customer (KYC) and Anti-Money Laundering (AML) requirements.

These processes often involve manual document analysis, fragmented information, and time-consuming investigations.

## Project Objective

Develop an agentic AI solution to assist banking compliance analysts with:

- Customer document analysis and information extraction
- Regulatory knowledge retrieval using RAG
- Detection of missing or inconsistent information
- Investigation report generation with source citations
- Human-in-the-loop validation

## Technology Stack

AI & Agents: Python, LangChain, LangGraph, RAG

Backend: FastAPI

Frontend: Streamlit

MLOps / LLMOps: MLflow, Docker, CI/CD, GitHub Actions

Version Control: Git, GitHub, GitLab
